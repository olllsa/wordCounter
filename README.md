# Word Counter - Поиск слов для QWERTY-клавиатуры

Многопоточная программа на C, которая находит слова, которые можно набрать на QWERTY-клавиатуре используя только соседние клавиши.

## Сборка

```
make
```

## Запуск

```
./counter <файл_словаря>
```

## Пример

```
./counter dictionary5000.txt
```

## Очистка
```
make clean
```

## Требования

   * GCC
   * pthread

## Примечания

   * Использует все ядра CPU

   * Показывает первые 100 слов

   * Только английские буквы a-z
